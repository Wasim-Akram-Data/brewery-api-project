## Overview
This Python project fetches brewery data from the Open Brewery DB API based on a US state and brewery type.

## Features
- Fetch brewery data using API
- JSON parsing
- Brewery type filtering
- Error handling
- Export data to CSV
- User-friendly console output

## Technologies Used
- Python
- Requests
- Pandas
- REST API

## API Used
https://api.openbrewerydb.org

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the project

python main.py
